# BTCUSDT SMC Alert Bot

## Project Goal
Build a python bot that monitors BTCUSDT market data and sends Telegram alerts.

## Strategy
- Detect a bearish liquidity sweep
- Comfirm a bearish market structure break.
- Confirm a lower low.
- Track an early-warning alert when price approaches witin $50 of that level from below.

## configuration
- Market: Binance  BTCUSDT
- Timeframe: 1 hour candles
- Alerts: Telegram
- Trading execution: Disabled
